# Jejak Teknisi Microscope V3.10.6 — Editor Layer PRO

Lanjutan dari V3.10.5.

## Fitur baru
- Layer objek untuk anotasi yang saling bertumpuk.
- Daftar seluruh objek anotasi dengan nomor dan tipe.
- Pilih objek langsung dari daftar Layer.
- **Ke Depan** untuk menaruh objek di paling atas.
- **Ke Belakang** untuk menaruh objek di paling bawah.
- Urutan layer mengikuti urutan gambar editor.
- Perubahan urutan layer masuk ke Undo/Redo.
- Tetap mempertahankan fitur V3.10.5: precision Jumper A/B, snap endpoint, zoom, crop, rotate, text/edit, save/share PNG.

## Build
GitHub Actions: Gradle 8.9 + JDK 17. Tidak menggunakan `android-actions/setup-android`.
Artifact: `jejak-teknisi-microscope-v3.10.6-debug`
