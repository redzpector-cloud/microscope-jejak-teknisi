# Jejak Teknisi Microscope V3.10.10

## Pilih PRO
- Seleksi memakai border cyan solid tipis dengan halo gelap agar tetap terlihat di atas PCB.
- Tidak memakai garis putih putus-putus.
- Tidak memakai handle kuning.
- Handle visual lebih kecil, tetapi area sentuh tetap besar agar mudah digunakan jari.
- Handle resize: putih + outline cyan.
- Handle rotasi: ring cyan + pusat putih.
- Endpoint Jumper A/B saat objek dipilih menggunakan cyan, bukan kuning.
- Tap objek lain berpindah seleksi.
- Tap area kosong melepas seleksi.
- Transform drag/resize/rotate, Layer, Undo/Redo tetap dipertahankan.
- Overlay seleksi hanya tampilan editor dan tidak ikut hasil Simpan/Share.
