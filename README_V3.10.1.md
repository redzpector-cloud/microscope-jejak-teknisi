# Jejak Teknisi Microscope V3.10.1

## Jumper PRO
- Jumper menampilkan jalur kabel yang jelas dengan dua pad endpoint.
- Endpoint ditandai A (awal) dan B (tujuan) saat jumper dipilih.
- Endpoint lebih mudah dipilih/disentuh untuk proses edit.
- Rotasi jumper sekarang ikut bekerja saat objek diputar.
- Fitur warna, ukuran, resize, rotate, duplicate, delete, undo/redo tetap memakai editor PRO V3.10.0.
- Simpan/Share tetap merender seluruh objek edit ke PNG.

Build menggunakan GitHub Actions dengan Gradle 8.9 dan JDK 17.
