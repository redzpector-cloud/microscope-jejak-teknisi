# Jejak Teknisi Microscope V3.3.5

## Editor gabungan
- Teks fixed-size saat zoom: posisi tetap mengikuti gambar, ukuran visual teks tetap.
- Pan/zoom gambar mempertahankan semua anotasi pada koordinat gambar.
- Selection overlay dihitung dari geometry objek dan transform gambar.
- Selection handle dan rotation handle tetap mengikuti objek.
- Toolbar editor dibuat lebih compact; panel warna/ukuran bersifat contextual.
- Pen, Panah, Lingkar, Garis, Kotak, Highlight, Jumper, dan Teks dapat memakai opsi warna/ukuran.
- LIVE dan tombol bawah kamera tidak diubah.
- Crop PRO, Undo/Redo, Simpan/Share dipertahankan.

## Catatan build
Build di GitHub Actions menggunakan Gradle 8.9 sesuai workflow repository.
