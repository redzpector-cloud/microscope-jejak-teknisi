# Jejak Teknisi Microscope V3.8.8

- Baseline dari V3.8.7.
- Ekspor hasil Freeze/Edit menggunakan PNG lossless agar teks, garis, panah, titik, highlight, jumper, OCR, dan objek lain tidak mengalami kompresi JPEG.
- Simpan dan Share menggunakan bitmap hasil flatten yang sama.
- Crop, Zoom, Rotate, Detail, Exposure, dan editor tetap dipertahankan.
- Workflow GitHub Actions menggunakan JDK 17 + Gradle 8.9 tanpa `android-actions/setup-android@v3`.
