# Jejak Teknisi Microscope V3.7

V3.7 adalah penyempurnaan dari V3.6 dengan fokus Microscope Live PRO.

- Preview kamera tetap luas dengan bottom sheet rendah.
- Bottom sheet drag + snap animation tetap dipertahankan.
- Panel LIVE auto-hide tetap aktif.
- Zoom, fokus, exposure, dan Ultra Detail tetap dipertahankan.
- Zoom dan exposure pengguna dipertahankan saat preview di-restart karena perubahan Detail.
- Editor PRO, Database eMMC, dan TEBAK eMMC tidak dihapus.
