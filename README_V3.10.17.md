# Jejak Teknisi Microscope V3.10.17

Select/Edit PRO refinement based on V3.10.16.

- Four visible corner handles remain the only resize handles.
- Corner resizing now follows the finger direction more naturally instead of relying only on radial distance from the object center.
- Resize remains proportional for a predictable annotation shape.
- Rotation handle remains unchanged.
- Drag, Undo/Redo, Layer, Jumper endpoints, Crop, Text, Save and Share are unchanged.
- Selection overlay remains UI-only and is not exported into Save/Share.
