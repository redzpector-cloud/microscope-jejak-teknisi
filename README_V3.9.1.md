# Jejak Teknisi Microscope V3.9.1

Stabilisasi Editor PRO berdasarkan V3.8.x.

- Mode Pilih dapat memilih objek anotasi.
- Objek terpilih dapat digeser.
- Handle 8 arah tersedia untuk resize.
- Handle atas tersedia untuk rotasi.
- Gesture 2 jari pada objek mendukung rotasi dan pengaturan ukuran stroke.
- Duplikat, Undo, Redo, dan hapus objek terpilih dipertahankan.
- Simpan/Share tetap menggunakan hasil editor.
- Crop dan rotate mempertahankan koordinat anotasi.
- Workflow GitHub menggunakan JDK 17 + Gradle 8.9 tanpa android-actions/setup-android@v3.

Catatan: build Android perlu dijalankan melalui GitHub Actions.
