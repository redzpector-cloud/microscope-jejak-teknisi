# Jejak Teknisi Microscope V3.8.4

- Baseline dari V3.8.3 yang sudah berhasil build.
- Simpan dan Share tetap selalu terlihat.
- Hasil Simpan dan Share menggunakan bitmap hasil flatten yang sama.
- Objek editor ikut dirender ke hasil: panah, titik, garis, lingkaran, kotak, highlight, jumper, teks, dan OCR.
- Crop/zoom mengikuti area Freeze yang sedang terlihat.
- Workflow GitHub Actions tetap menggunakan JDK 17 + Gradle 8.9 tanpa `android-actions/setup-android@v3`.
