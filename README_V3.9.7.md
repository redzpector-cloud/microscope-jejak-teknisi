# Jejak Teknisi Microscope V3.9.7

## Editor PRO — Select & Multi-touch Stability
- Selection badge menunjukkan jenis objek yang sedang dipilih.
- Multi-touch hanya membuat satu checkpoint Undo untuk satu gesture transform.
- Rotasi bebas 360° dan indikator sudut tetap realtime saat rotating.
- Handle resize/rotasi dan transform objek dipertahankan dari V3.9.6.
- Simpan/Share tetap merender seluruh objek anotasi ke PNG.
- Versi aplikasi: 3.9.7 (versionCode 397).

Build melalui GitHub Actions menggunakan Gradle 8.9 dan JDK 17.
