# Jejak Teknisi Microscope V3.10.3 — Editor Style PRO

Peningkatan dari V3.10.2:
- Warna dan ukuran yang dipilih sekarang menjadi **preset untuk objek baru**, bukan hanya objek yang sedang dipilih.
- Jumper baru mengikuti warna aktif dan tetap memakai ukuran aktif.
- Jika objek sedang dipilih, perubahan warna/ukuran langsung diterapkan ke objek tersebut.
- Undo tidak dibuat jika warna/ukuran sebenarnya tidak berubah.
- Teks Share tidak lagi menampilkan nomor versi lama.
- Fitur Jumper A/B, Move, Resize, Rotate, Duplicate, Hapus, Undo/Redo, Simpan dan Share tetap dipertahankan.

Build: GitHub Actions, JDK 17, Gradle 8.9.
