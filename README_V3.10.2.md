# Jejak Teknisi Microscope V3.10.2 — Jumper Endpoint PRO

Peningkatan dari V3.10.1 untuk editor Jumper:
- Endpoint Jumper A dan B dapat dipilih dan digeser secara terpisah.
- Area sentuh endpoint diperbesar agar lebih mudah digunakan di layar HP.
- Endpoint tetap mengikuti rotasi Jumper.
- Marker A/B dibuat lebih jelas saat Jumper dipilih.
- Fitur Select, Move, Resize, Rotate, warna, ukuran, Duplicate, Hapus, Undo/Redo tetap dipertahankan.
- Simpan/Share tetap merender seluruh objek edit ke PNG.

Build tetap menggunakan GitHub Actions, JDK 17, dan Gradle 8.9.
