# Jejak Teknisi Microscope V3.10.12

## Pilih PRO UX
- Seleksi tidak langsung bergerak karena jitter jari saat tap.
- Drag baru dimulai setelah perpindahan minimal 10dp.
- Tap objek tetap hanya memilih objek.
- Tap area kosong tetap melepas seleksi.
- Tap singkat pada teks tetap membuka editor teks.
- Drag teks tidak lagi salah dianggap sebagai tap sehingga tidak membuka editor.
- Undo untuk perpindahan objek dibuat hanya ketika drag benar-benar dimulai.
- Resize, rotate, jumper endpoint, Layer, Undo/Redo dan export tetap dipertahankan.
