# Jejak Teknisi Microscope V3.3.1

Editor Select & Transform.

- Pilih objek anotasi.
- 8 handle untuk resize.
- Handle rotasi untuk memutar objek.
- Pen ikut ditransform sebagai satu objek.
- Panah, lingkar, kotak, garis, titik, teks, OCR, dan jumper dapat dipilih.
- Zoom/pan gambar tetap memakai frozenMatrix sehingga anotasi tetap menempel pada gambar.
- Undo/Redo tetap tersedia.

Catatan: build dilakukan melalui GitHub Actions project pengguna.
